# Super Dodgeball — 联机 MVP

Unity 6.3 LTS / URP 的 Windows 可独立运行原型。提供极简主菜单、直连房间、实体投球大厅、选队、更衣间、双队休息间、入场倒计时比赛、结算、重赛、暂停和保存设置。角色、圆角球场和道具在 Unity 中生成，无外部模型、动画或付费素材。

## MVP 试玩

独立版本位于 `Builds/SuperDodgeball-MVP`，运行 `SuperDodgeball.exe`；分享时发送整个文件夹或压缩包，不能只复制 exe。无需安装 Unity。编辑器中打开 `Assets/SuperDodgeball/Scenes/SoftPlayground.unity` 后进入 Play，也会显示同一套菜单。

- **主界面**只有开始游戏、设置、退出游戏。开始后进入默认四个人机的可走动大厅。
- **大厅大屏**通过实际投球碰撞选择：前往休息间、添加或移除人机、时长、人机难度、观众干扰、武器空投。规则与出发由房主控制。
- **左右选队**：走上薄荷或蜜桃色区域选择队伍；人机围绕真人选择自动平衡。最多五名角色，每队最多三名真人，所有参赛者分队且两队都有人才能出发。
- **更衣间**在大厅后方左侧，走进去用球砸衣柜，选择基础身体、帽子或运动套装。也可在更衣间内按 C 切换；保存到本机，联机同步，跨场景和重赛保留。
- **叫上朋友**：大厅后方右侧用球砸“开放房间”；移除人机给朋友留位。朋友从自己的大厅砸“加入朋友”，输入房主地址和相同端口（默认 7777）。双方需在同一局域网或已连通的虚拟局域网。多网卡时分享实际互通的 IPv4 地址。暂不提供 Steam 邀请、公网中继或房间码，比赛中不能加入。
- **休息间与进场**：房主砸大屏出发后，两队分别到自己的休息间。可用球砸道具柜每局领一件道具、砸六项技能牌消耗升级点。真人走过门进入本方半场后，同队人机会跟进；纯人机队会自行入场。双方全员在场才开始世界内 3–2–1，期间有人退出球场就取消并重置倒计时。
- **两队比赛**：倒计时结束才运行比赛时钟、观众与空投。命中敌队为本队得分；同队球不造成受击或计分。结束显示两队总分、个人命中和被击中次数；房主可返回同一大厅再来一局。
- **暂停与设置**：Esc 打开设置、帮助或离开入口。单人暂停冻结世界，联机菜单只停止自己的操作。房主退出会关闭房间并让客户端返回主菜单；暂不支持断线重连或房主迁移。音量、灵敏度、显示模式、画面质量和名字保存在本机。

大厅、队伍名单、规则与入场倒计时都位于场景内；活动时只保留准星和临时鸡蛋遮挡。中央四面吊屏和两端大屏显示开赛 3、2、1、双方比分、比赛时间和结算结果。

首轮联机使用房主权威：客户端只发送操作，房主统一模拟移动、蓄力、投球、命中、礼盒认领、人机、观众与得分；约每秒 20 次同步物理骨架和场内对象，客户端平滑呈现，操作约每秒发送 30 次。此版本以局域网体验为目标，尚无客户端移动预测、延迟回溯、Steam 服务器或公网匹配服务，高延迟手感仍需后续优化。

## 开始试玩

1. 打开 `Assets/SuperDodgeball/Scenes/SoftPlayground.unity`，点击 Unity 顶部的 Play。旧的 `DodgeballPlayground.unity` 场景仍保留。
2. 点击“开始游戏”，走到左右两侧选队；用球砸大屏“前往休息间”，从休息间走进本方球场。
3. 开局后约三秒出现降落伞空投。先用球砸中箱子直接领走武器，再向其他参赛者投球。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 转动第三人称镜头 | 鼠标 |
| 拉近瞄准并蓄力 | 按住鼠标右键 |
| 投球 | 点击鼠标左键 |
| 向左 / 右侧弯 | Q / E |
| L 型弯腰 / O 型卷身 | 按住 Z / X |
| 更衣间内切换基础身体、帽子、运动套装 | C / 投球砸衣柜 |
| 向移动方向飞扑；不移动时向前扑 | 空格 |
| 切回普通球 / 使用已有的空投武器 | 1 / 2 |
| 打开或关闭暂停菜单 | Esc |

MVP 默认三分钟限时比赛。操作提示和设置在菜单，比赛不显示额外的蓄力条或弹道预览，结束后才显示排行榜。侧弯持续约 0.72 秒，之后需要恢复；松开按键才能再次触发。五连发每次发射五颗球，发射间隔约 0.1 秒，整次攻击冷却 2.2 秒。早期练习场的 T/B/V/H/R 调试键在正式菜单流程中关闭，避免客户端改写房主规则。

## 摸鱼裁判与越线犯规

正式开赛后裁判先摸鱼约 8 秒，之后在摸鱼 7–10 秒、回头预警 2.2 秒、认真执法 4.5–6 秒之间循环。边线裁判会读报、喝饮料、转身巡视；场内双面标牌与中线颜色显示状态，回头有提示音。活动时不增加屏幕 HUD。

只有认真执法时持续越过中线约 0.35 秒才抓现行；中线有 0.65 米容差，空中飞扑同样按根部位置判定。被球击倒或打飞的布娃娃恢复期间有额外缓冲，避免把被动位移当成故意犯规。摸鱼和回头预警期间可以撤回。

前两次吹哨出示黄牌，以短暂纠正动作送回本方半场。25 秒没有新增处罚会消退一次警告；第三次召唤两名保镖，跑来把角色架起，穿过本方通道押回休息间。整段处罚约 4.5 秒后自动回到本方半场，清除警告并恢复移动。处罚期间不能出手或利用自己已有的球刷分，也不会成为对手刷分的靶子。单人暂停冻结裁判与保镖，联机菜单不冻结比赛。重赛清空处罚。

机器人使用同样的裁定：斗士会趁摸鱼越线前压，预警和执法期间撤回；其余性格偏保守。裁判状态、吹哨、警告和押送由房主统一决定并同步到客户端。

棒球棍和充气锤支持近战命中得分；奶茶延长下一次摸鱼窗口，做贼心虚与装乖高手参与裁判机制。

## 空投武器

空投用降落伞落向球场中部，地面有彩色落点圈，箱子上展示武器外形。普通球和特殊球都可以争抢空中或落下的箱子：第一颗有效命中箱子的球，把武器直接交给该球的发射者。走过去接触箱子不算认领，发球机关、已经命中过人的球和旧回合的球也不能领奖。墙体会挡住抢箱子的投球。联机时由房主在物理步中裁定首次有效命中并同步武器归属。

每个角色同时保留一把特殊武器，新的空投会替换旧的装备。按 1 暂用无限普通球，按 2 切回已经获得的特殊武器；没有装备时按 2 不会凭空得到武器。每个箱子提供三次特殊攻击：

- **升天保龄球**：更大的紫色球，带三个指孔，速度比普通球慢，冷却约 1.25 秒。击中会把整个人向上掀飞，空中保持布娃娃，落下后恢复。右键蓄力仍然有效，速度约 14 到 24。
- **五连发**：每次攻击发射五颗球；一次攻击消耗一次弹药，三次共十五颗。最后一次攻击仍完整发射五颗。

手里的球会按武器改变颜色和外形。弹药用完自动回到普通球，受击会取消尚未出手的攻击，已经预留的这次弹药不会退回。空投被认领或超时消失后约 10–15 秒再产生下一个，位置和奖励随机，同时最多一个箱子；箱子约 23 秒后消失。单人暂停会冻结空投和物理身体，联机暂停菜单不冻结其他人。开始新局会清除空投、武器和场上球。

新增四种特殊武器，同样每盒三次攻击：

- **棒球棍**：约 2.35 米近战挥打，把对手掀飞；挥棒窗口可以回击来球并变更球的归属，也能打回定时炸弹，保留剩余引信。
- **充气大锤**：较慢出手、约 2.65 米范围，把对手拍倒后短暂压扁，实际脊柱与身体命中跟着变化；不能隔墙或伤害同队。
- **拳套火箭筒**：发射粉色拳套，真实碰撞命中后强力击退、击飞。
- **定时炸弹**：抛出带三秒倒计时的弹跳炸弹，约 3.5 米爆炸范围。墙壁阻挡爆炸，队伍和裁判保护继续生效；每人每次爆炸最多记一次命中。不是接触即爆。

## 携带道具与每局技能

一件携带道具与特殊武器分别占槽，**F** 使用。休息间每局可用球选领一件起始道具，后续从随机空投争抢；新的道具替换旧道具。

- 泡泡皂：清除蛋渍并获得八秒防蛋；旧的观众肥皂礼盒仍为即时洗净。
- 香蕉皮：放在瞄准方向最多六米内，短暂布置后踩到会滑倒，包括自己和队友，不计进攻得分。
- 假人替身：放下七秒充气假人，吸收一次敌方球后漏气；可吸引有视线的敌方机器人，同队球可穿过。
- 裁判奶茶：下一次摸鱼窗口延长六秒，双方共享；最多预约一杯，已预约时保留道具，不能打断正在预警或执法的裁判。
- 弹簧鞋：二十秒内下一次飞扑更高更远，用后失效，仍可被命中。

每局开局一升级点，之后每三次有效命中/近距离主动闪避获得一点。休息间用普通球砸技能牌升级，每项每局一次；比赛中可自行撤回本方休息间，比赛计时继续。六项分别为：橡皮腰（更深侧弯、更快恢复）、飞扑接力（飞扑躲过近球后缩短再次飞扑等待）、回马枪（飞扑落地后下一球更快出手）、快递投手（普通投球更快出手）、做贼心虚（裁判回头时向本方撤退加速）、装乖高手（警告由二十五秒缩短至十五秒消退）。重赛清空技能、道具、临时效果与升级点。

机器人会实际投球购买休息间升级，争抢和使用道具，使用新武器并躲避将爆炸的炸弹。新增状态和效果由房主决定，联机同步技能、携带道具、挥棒、炸弹、假人、香蕉皮和裁判奶茶。

## 场边观众

两侧看台共有 96 个会挥手、起哄、蓄势投掷并能被击倒的卡通观众。开局先留出六秒准备，之后约每 3.8–5.5 秒随机发生一次投掷：臭鸡蛋约占 55%，泡泡皂约占 21%，其余是武器礼盒（保龄球或随机特殊武器）。场上最多保留两个观众礼盒，独立于原有的单个降落伞空投。

观众先挥臂蓄势约 0.9 秒，地面出现对应颜色的落点圈，随后抛出实物。臭鸡蛋在预警开始时锁定目标位置，沿抛物线飞行，不会追踪；可以移动、摆姿势躲开，也可以利用障碍遮挡。观众会在双方角色之间轮换目标，同一个角色至少间隔八秒才可能再次被选中。

- **臭鸡蛋**：命中实际身体后破裂，在玩家屏幕留下蛋白、蛋黄和下垂污渍，约 3.6 秒后自动淡出；准星仍可见。持续期间再中蛋不会刷新时长。鸡蛋不会造成球的伤害或击倒，机器人被砸中也会降低瞄准精度、增加反应时间，脸上能看见蛋渍。
- **泡泡皂礼盒**：薄荷色盒子上展示肥皂和泡泡。用自己的球先砸中，就能清除污渍并获得八秒防蛋效果，期间角色周围冒出泡泡。不会替换武器，也不防普通球或保龄球。
- **武器礼盒**：仍然是谁先用自己的有效球砸中，武器就直接归谁，包含空中争抢。奖励和原有空投一致，每盒三次攻击。机器人也会争抢观众礼物，被蛋砸中时会寻找肥皂。

观众设置由房主在大厅选择，玩家不能在比赛中改写。单人暂停冻结蓄势、投掷物和状态时长；新局清除所有礼盒和污渍。联机时鸡蛋命中、肥皂状态和武器归属均由房主判定并同步。

## 智能对手

单人大厅默认开启四个机器人，联机房间可以按空位逐个添加。它们使用和玩家相同的 CharacterController、物理身体、蓄力投球、空投认领、特殊武器、碰撞和布娃娃恢复路径；机器人不会瞬移、直接修改球的位置或凭空获得装备。它们观察球、箱子、视线和其他角色，再决定移动、蓄力、投掷或躲避。

四个角色有不同偏好：斗士更愿意靠近玩家，拾荒者更优先抢箱子，杂技者反应更快且更常用侧弯、O 型或飞扑，投手更喜欢拉开距离并进行较长蓄力。机器人有反应延迟、瞄准误差和有限目标记忆；受到攻击后会记住发球者，但同一时间最多两个机器人主动锁定玩家。墙会阻挡视线，单人暂停会冻结机器人决策和移动；联机房主切出窗口时机器人继续比赛。

MVP 通过大厅配置机器人；旧练习场的调试路径仍供编辑器检查使用。这个版本的智能是可预测、可调试的本地游戏 AI，不依赖联网大模型；后续可以在它的观察和决策层接入更复杂的行为树、Utility AI，或把真正的 AI 服务用于比赛分析、教练和关卡生成。

右键保持约 1.25 秒可以蓄满，左键投球。手臂逐渐后收、肘部弯曲、身体后仰转肩并抬起前腿，镜头逐渐推进，满蓄力有轻微震动和背景虚化。左键启动向前甩臂，球在约 0.22–0.34 秒后从物理手的位置释放，然后身体前倾、手臂完成随挥并平滑恢复。普通球初速度约 17，蓄满后约 34；右键松开取消未使用的蓄力。五连发使用整组开始时的蓄力，每颗球朝当前瞄准方向投出。

每个角色由 18 个真实刚体、17 个关节组成，其中躯干为八段物理脊柱。连续曲面跟随物理骨架弯曲，肘和膝也能自然弯曲。碰撞和命中使用实际物理身体。被球击中时释放骨盆支撑，按命中方向摔倒，约 0.85 秒后开始恢复支撑，随后约 0.65 秒恢复控制。四肢会继续回稳，受击会中断蓄力和未发出的球。

Z 的 L 型把弯曲分散在腰部，X 的 O 型用卡通拉伸把躯干围成环，厚度保持圆润，手臂收在环外。姿势在按住时维持，最长 1.4 秒，之后恢复约 0.55 秒，需要松键才能再次触发。姿势期间移动较慢，不能蓄力、投球或飞扑；身体可以被实际命中，O 中间留出的空隙允许球穿过。

更衣间内按 C 或用球砸衣柜可选择三种样例：基础身体、棒球帽、棒球帽加背心短裤。帽子挂在物理头部的插槽；背心和裤子采样身体及腿部相同的变形曲线。装扮不增加命中范围，换装不会堵住 O 型洞口。已提供实体更衣间、本地装扮存档与联机同步；尚未制作大量服装，也不是任意网格服装自动适配工具。

飞扑会真正起跳并向输入方向腾空，静止时向镜头朝向扑出：飞行约 0.6 秒，根部抬升约 0.9 米，整体前进约 5–6 米。双手前伸、身体横展、双腿带向身后，真实身体通过关节跟随轨迹。实际触地后有约 0.18 秒的低姿态缓冲，再平滑起身，之后约 1.3 秒恢复。腾空时低球可以从身下穿过，打到身体仍会受击并转入布娃娃，没有额外无敌时间；飞扑期间不能投球，也不能在空中连跳。人机使用相同的起跳与落地规则，联机由房主模拟并同步身体。单人暂停会保留未完成的飞扑。

发球机关先锁定身体中线并显示红色预警，然后向该位置发球。球不会追踪角色；在球接近时侧弯，可以让球从原来的头部位置穿过。站着被击中、移动避开和摆姿势避开，都可以在这里反复比较。

## 当前范围

- 柔和的奶油、蜜桃、薄荷与淡紫配色；室内体育馆、浅木地板、顶棚灯架、圆角场地和圆润角色。
- 跑动有平滑起停、轻微后仰、呼吸、挤压回弹、手脚摆动与白色脚步泡泡；投球有蓄势和出手反馈，飞扑结束有恢复和泡泡。
- 第三人称肩后镜头、平滑跟随、随蓄力继续推近、背景轻度景深、跑动时轻微扩大视野，以及镜头与墙体避让。摇晃幅度保持较小。
- 移动控制与物理身体分离；站立时关节驱动跟随动作，受击时身体交给物理模拟并恢复。不是完整复刻《人类一败涂地》的攀爬、抓取和全物理移动系统。
- 躯干与四肢使用连续曲面，躯干由多段物理骨骼驱动，极端姿势可拉长身体而保持截面厚度。身体、衣服和命中区域共享这套变形结构。
- 球有重力、抛物线、落地与碰壁反弹、速度损失、旋转、拖尾和短暂挤压；仍沿飞行路径进行球形扫掠检测，避免高速球穿过身体。球高于矮护栏时可以飞出场地。
- 一颗球命中角色后失去伤害并弹开，不会反复刷分；连续弹跳也会使球失去伤害。
- 四种不同性格的人机，可由房主在大厅添加和移除；早期的发球机关保留供诊断使用。
- 无限普通球、有限弹药的空投五连发与升天保龄球、命中反馈、简单音效、内部计分与重置。

当前提供局域网/直连真人对战及人机混合比赛；尚未接入 Steam 好友房间、公网中继、抓取、捡球或正式关卡内容。球的重力和反弹由可调的运动模拟实现；角色使用关节布娃娃，并非软体网格模拟。

## 构建与检查

游戏脚本位于 `Assets/SuperDodgeball/Scripts`。角色尺寸、材质、场地和初始对象由 `Assets/SuperDodgeball/Editor/DodgeballSceneBuilder.cs` 创建，生成的场景本身也可以直接在 Unity 编辑器中调整。

Unity 顶部的 **Super Dodgeball** 菜单提供：

- **Build Windows MVP**：构建 Windows 64 位开发试玩版到 `Builds/SuperDodgeball-MVP`，结果记录在 `work/mvp-build.json`。
- **Run party arsenal checks**：验证新武器真实命中、炸弹计时与遮挡、携带道具、六项技能、休息间实体选牌和清空重赛。
- **Run MVP flow checks**：在 Play 模式验证菜单状态、房间配置、暂停、计分、结算、重赛和端口关闭等完整流程。
- **Run airborne dive checks**：验证真实起跳、飞行碰撞、暂停、触地缓冲与空中受击，并记录侧面动作截图。

- **Build Soft Playground**：重新生成第二版原型场景。会替换该场景中的手动修改，使用前先保存版本；旧场景和旧材质保留。
- **Validate collision geometry**：在编辑模式检查站立命中、左右侧弯躲避、忽略发射者和墙体遮挡。
- **Upgrade articulated characters**：为当前场景的旧角色添加肘、膝及布娃娃组件，保留场地和其他场景编辑。
- **Upgrade elastic body**：为当前场景中已有肘膝的角色添加八段脊柱，保留场地编辑。新创建的角色自动包含这套结构。
- **Add sideline spectators**：为当前场景添加两侧观众，保留已有场地和角色；重复执行不会重复生成。
- **Run Play checks**：在运行模式用临时输入设备验证真实操作、蓄力、飞扑、弹跳、变形、穿洞、换装、空投认领、武器弹药、击飞恢复、智能对手和观众干扰。约两分钟完成，结束后恢复输入设备及焦点设置并重置回合。此检查代码只在编辑器中编译，不进入玩家版本。

检查结果写入本地 `work/geometry-check.json` 和 `work/play-check.json`。`work`、Unity 缓存及构建目录已排除在版本管理之外。

开发前的项目已保存为本地 Git 版本，原来的 `SampleScene` 保留。

开发版还包含仅由明确命令行参数启动的多进程验证器 `DodgeMvpSmoke`，用于验证两名真实客户端和房主、人机在同一房间的完整对局，不会在普通启动时启用。

球场长宽扩大 25%，地板由 22×28 米调整到 27.5×35 米。护栏、边线、看台、裁判和休息间入口同步移动；人物、武器大小和移动速度保持原值。

室内体育馆：保留 27.5×35 米球场，加入浅木地板、围墙、顶棚、屋顶灯架和休息间封闭外壳。中央四面吊屏与两端墙屏共六面，正式开赛前显示 3、2、1，开赛后显示薄荷队/蜜桃队比分与房主比赛时钟，结算显示胜负、重赛清零。记分牌在场景内，比赛 HUD 仍只保留准星。可用菜单 Upgrade to indoor stadium 更新场馆外壳而保留角色和场地；Build Soft Playground 也会自动创建室内场馆。

美式看台与观众交互：两侧各四排、十二座，共 96 张独立座椅，包含扶手、杯架、分区牌、中央及两端楼梯。观众使用六个刚体和关节，普通球、保龄球、拳套、近战和炸弹均可触发物理翻倒；真实座椅、台阶和墙面参与碰撞。受击会打断尚未出手的观众投掷，约四秒内平滑恢复入座，暂停冻结，重赛清零。命中观众不增加队伍得分或技能经验；最多十名观众同时进行物理反应，其余保持坐姿，联机同步由房主模拟的身体。玩家、观众、替身及场内人员去除眼睛、嘴巴与腮红，保留干净的圆润造型。
